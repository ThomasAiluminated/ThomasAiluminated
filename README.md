### 🧰 Claude Skills for Education

Open, free skills that help teachers and trainers use AI with sound pedagogy, and keep the teacher in charge.
<br>👉 **[Browse the collection](https://github.com/ThomasAiluminated/claude-skills-for-education)** · **[Website](https://thomasailuminated.github.io/claude-skills-for-education/)**

| | Skill | What it does |
|---|---|---|
| 💬 | [Edu Prompt Coach](https://github.com/ThomasAiluminated/edu-prompt-coach) | Ready-to-paste prompts for teachers, with the pedagogy behind them |
| 🗓️ | [Lesson Designer](https://github.com/ThomasAiluminated/lesson-designer) | Lessons from learning objective to exit check |
| 📏 | [Rubric Builder](https://github.com/ThomasAiluminated/rubric-builder) | Fair rubrics with observable levels and a student version |
| ✅ | [Assessment Item Writer](https://github.com/ThomasAiluminated/assessment-item-writer) | Test questions with plausible distractors and feedback |
| ✍️ | [Feedback Writer](https://github.com/ThomasAiluminated/feedback-writer) | Specific, actionable feedback on student work |
| 🌈 | [Inclusive Lesson Adapter](https://github.com/ThomasAiluminated/inclusive-lesson-adapter) | Accessible materials with UDL, same learning objective |
| 🏗️ | [Learning Program Designer](https://github.com/ThomasAiluminated/learning-program-designer) | Training programs from need to evaluation |
| 🧭 | [Prompt Architect](https://github.com/ThomasAiluminated/prompt-architect) | Rough requests turned into strong prompts for Claude |
